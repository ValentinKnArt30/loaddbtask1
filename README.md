# ДЗ: сравнение хранимых процедур `dorepeat_v1` и `dorepeat_v2`

## Цель

Сравнить время отклика хранимых процедур `dorepeat_v1` и `dorepeat_v2` с помощью Apache JMeter.

## Состав работы

- `test/jmeter/` — сценарий JMeter (`wp_db_test.jmx`).
- `results/screenshots/` — скриншоты графиков времени отклика.
- `README_jmeter.md` — описание теста и результатов.

## Среда тестирования

- Apache JMeter: **5.6.3**.
- СУБД: **MariaDB 10.5.8**.
- JDBC-драйвер: MySQL Connector/J 8.4.0.
- Класс JDBC-драйвера: `com.mysql.cj.jdbc.Driver`.

Файл `mysql-connector-j-8.4.0.jar` должен находиться в каталоге `lib` используемой установки JMeter. После добавления драйвера JMeter необходимо перезапустить.

## Сценарий

Выполняются вызовы двух процедур:

1. `dorepeat_v1`.
2. `dorepeat_v2` — с передачей текстового параметра `p2`.

Для сопоставимости результаты следует получать при одинаковых настройках нагрузки: одинаковом количестве потоков, количестве итераций/длительности теста и времени разгона. Конкретные значения необходимо указать по фактической конфигурации `wp_db_test.jmx`.

## Результаты измерений

Находятся в папке `results/screenshots/` скриншоты графиков JMeter, на которых видны название графика и оси. 

### Вывод

По результатам проведённого тестирования **dorepeat_v1 затратила меньше времени**. Сравнение действительно только для указанных условий теста; вывод не следует обобщать на другую нагрузку без дополнительных измерений.

## Как воспроизвести тест

1. Запустить сервис и базу данных согласно `docker-compose.yml` проекта.
2. Убедиться, что процедуры созданы в нужной базе и пользователь БД имеет права на их вызов.
3. Проверить JDBC URL, имя пользователя и пароль в `JDBC Connection Configuration` сценария JMeter. Не храните реальные пароли в публичном репозитории.
4. Убедиться, что в поле `JDBC Driver class` задано `com.mysql.cj.jdbc.Driver`.
5. Открыть `wp_db_test.jmx` в JMeter и выполнить тесты для обеих процедур с одинаковыми настройками нагрузки.
6. Сохранить графики.

## Примечание по конфиденциальности

Не публикуйте в GitHub пароли, токены, пользовательские данные, дампы базы с персональной информацией или локальные файлы с секретами. JDBC-драйвер обычно достаточно указать в инструкции, а сам JAR не обязательно коммитить в репозиторий.
